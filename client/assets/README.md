# Иконка Office Desk & Gear

`icon.png` — исходный PNG 1254×1254, создан встроенным imagegen 1 ноября 2026.
Иконка подключена к Android launcher через `buildozer.spec` и к desktop через
`OfficeDeskGearApp.icon`. На телефоне установщик масштабирует исходник в mipmap.
Пустые поля вокруг знака оставлены для круглых и скруглённых масок Android.

`presplash.png` — фирменная заставка Android 720×1280, подключённая через
`presplash.filename` в `buildozer.spec`. Она отрисована из того же `StartupScreen`,
который появляется при запуске клиента. Статическая заставка сопровождает загрузку
Python, затем приложение показывает анимированную полосу прогресса.
Для обновления PNG после изменения дизайна: `python scripts/render_presplash.py`.

Итоговый промпт: квадратная непрозрачная иконка Office Desk & Gear; тёмно-синий
фон `#0b1018`, крупный светло-голубой рабочий стол с монитором и синяя шестерёнка
справа внизу; лаконичная плоская геометрия, контраст при 48 px, знак внутри
центральных 64% квадрата; без надписей, QR, рамки телефона и водяных знаков.
