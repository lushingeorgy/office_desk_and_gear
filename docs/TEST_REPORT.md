# Проверка Office Desk & Gear

## Проверка учебных кейсов 11 ноября 2026

Изолированная кандидатная версия проверена на PostgreSQL 18 и Python 3.12.
Зависимости установлены заново из requirements.txt и requirements-dev.txt в
отдельное окружение. pip check не обнаружил несовместимых зависимостей.

- PASS — общий unittest discover, 38 тестов верхнего уровня, включая запуск
  отдельного набора из 40 PostgreSQL-проверок. Проверены миграции пустой БД,
  переход с 0002 на 0003, остановка на старых дублях с сохранением данных,
  UNIQUE NULLS NOT DISTINCT, CHECK, публичные роли, отзыв JWT, CRUD,
  конкурентное бронирование, ошибки и согласованность статусов техники.
- PASS — настоящий Kivy, навигация, формы и узкий экран. Длины модели,
  серийного и инвентарного номеров ограничены 128 до запроса. Этаж 0 и
  нулевое число розеток сохраняются в форме. Показ пароля сохраняет пробелы.
  Полный список загружается порциями, выбор назначения доступен для всех столов.
- PASS — отдельный floor_plan_runtime на ширине 320 и 420, прокрутка до
  последнего стола, касания и переходы по этажам.
- PASS — 81 этап Kivy → HTTP → PostgreSQL в двух процессах, включая
  регистрацию сотрудника, профиль, изменение пароля, CRUD, фото,
  отчёты, восстановление входа и очистку при выходе.
- PASS — четыре независимые проверки рецензента. Все 43 защищённые операции
  без токена возвращают 401. Проверка токена выполняет один SELECT,
  список профилей загружает связанные брони ограниченным числом запросов.
  Искусственная ошибка после flush откатывает обращение, события и
  уведомления, клиент получает безопасную ошибку 500.

В кандидатной версии публичная регистрация создаёт employee. IT-администратор
назначает повышенные роли через защищённый API или серверную CLI. Результаты
относятся к исходному коду и настольному Kivy. Android APK 1.1.7 собран до
этих изменений. Новая сборка APK и размещение обновлённого API требуют
отдельной проверки. Исторические результаты ниже относятся к указанным датам.

страницы API по 200 мест, а в плане показывает один выбранный этаж со всеми
его секциями. Справа находятся номера этажей и стрелки вверх/вниз; они
остаются на месте при прокрутке столов. Выбор этажа сохраняется при возврате
к поиску и применяется при переключении на список. Смена этажа не требует HTTP.

три страницы API, сохранение времени поиска, пустой ответ и отсутствие
смешивания точных и ослабленных совпадений фильтра розеток. Использованы

Журнал: `tests/client_navigation_runtime-current.log`.

Физический телефон в этом проходе не проверен: локальный ADB 37.0.1

## Нейтральная тема и поиск по времени — 7 ноября 2026

Интерфейс переведён на чёрный, белый и нейтральные серые оттенки, включая
встроенные Material-компоненты, регистрацию, навигацию и заставку.
Свободные столы отмечены зелёным, занятые — красным в списке, на плане
и в карточке. Статусы сопровождаются текстом; выведенные из эксплуатации
места имеют отдельную подпись. Референсы и палитра описаны в [DESIGN.md](DESIGN.md).

В поиск добавлены начало и окончание в формате ЧЧ:ММ. Применённый интервал
сохраняется при переключении вида, фильтров и страниц, входит в ключ кэша
и подставляется в форму брони. Бронирование по действующему API остаётся
целочасовым: неполный час округляется вверх с пояснением; время окончания
обновляется при изменении начала и длительности. Для ночных броней сохраняется
дата окончания, поиск более чем на 24 часа отклоняется.

Результаты:

  сценарии проверяют пересечения, соприкасающиеся границы, часовые пояса,
  отменённые брони, недоступные столы и некорректные интервалы.
  Лог: `tests/artifacts/full-suite.log`.
- PASS: 23 этапа настоящего окна Kivy без сервера. Проверены нейтральные

  Лог: `tests/navigation-current.log`; снимки: `tests/artifacts/navigation/`.
