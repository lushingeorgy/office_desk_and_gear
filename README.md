# Office Desk & Gear

Мобильный клиент на KivyMD 2.0 и API на FastAPI с PostgreSQL.
Сейчас в клиенте реализована регистрация: ФИО, выбор одной из трёх должностей,
почта, пароль и повтор пароля. API бронирования, оборудования, заявок и
аналитики сохранены. Авторизация использует сессии в PostgreSQL.

## Запуск на компьютере

Нужны Python 3.12 и работающий PostgreSQL с базой `office_desk_gear`.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Укажите свой пароль в `PGPASSWORD` файла `.env`. При необходимости измените
`DATABASE_URL`. Программа создаёт отсутствующие таблицы внутри существующей
базы PostgreSQL.

```powershell
.\.venv\Scripts\python.exe main.py
```

На компьютере `main.py` запускает локальный API, дожидается готовности и
открывает интерфейс. После закрытия окна собственный сервер останавливается.
Уже работающий сервер используется повторно и не останавливается.

Для запуска только API:

```powershell
.\.venv\Scripts\python.exe run_app.py
```

Документация API: <http://127.0.0.1:8000/docs>.

Время бронирования хранится в локальном времени сервера без часового пояса.
Даты с часовым поясом (например, `2026-10-29T09:00:00+03:00` или с `Z`)
перед проверкой пересечений и сохранением переводятся в локальное время
сервера. Даты без часового пояса уже считаются локальными. Это правило
применяется и к началу/концу периода бронирования; API возвращает локальное
время без смещения.

## Мобильный клиент

На Android и iOS `main.py` запускает только интерфейс. API и PostgreSQL
работают отдельно. Адрес API задаётся переменной `DSH_API_URL`; адрес
`127.0.0.1` на телефоне указывает на сам телефон. Настройки сборки APK/IPA
пока не добавлены.

## Проверки

Тесты PostgreSQL создают отдельную временную схему в настроенной базе и
удаляют её после завершения. Тест запуска кратко открывает окно приложения.

```powershell
.\.venv\Scripts\python.exe tests/test_postgresql.py
.\.venv\Scripts\python.exe tests/test_launcher.py
```

В репозиторий не включаются `.env`, локальное окружение, базы данных,
резервные копии и результаты запусков.
